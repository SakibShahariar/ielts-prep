# IELTS Listening: Strategies and Error Analysis

## 1. The multi-tasking skill

Listening requires you to **listen, read the questions and write answers simultaneously**.
Practice this as a skill, not just as "English listening".

## 2. Prediction (before the recording starts)

For each question:
1. Read the instructions — word limit and answer format.
2. Underline keywords in the question.
3. Predict the **word type** (noun, number, date, adjective, name).
4. Predict the **kind of meaning** expected (a place, a problem, a reason).
5. If possible, predict a likely word or phrase — but keep an open mind.

Prediction focuses your listening and makes paraphrases easier to recognise.

## 3. Keywords and paraphrase

The recording rarely repeats the question wording. Expect paraphrase:
`job → position`, `cheap → inexpensive`, `problem → issue`, `children → kids/young learners`.
Listen for the meaning, not the exact word. If you miss an answer, **do not panic** —
guess something, write it, and move on immediately so you do not lose the next answer too.

## 4. Section-by-section strategy

- **Part 1 (social conversation):** usually the easiest. Focus on numbers, names, addresses,
  dates and spelling. Names are often spelled out letter by letter. Check plurals.
- **Part 2 (single speaker, social):** likely a map/tour or facilities talk. Track location
  and direction. Watch for changes to the original plan.
- **Part 3 (educational conversation):** two or more speakers with opinions. Track **who**
  holds which view. Watch for disagreements and changing opinions.
- **Part 4 (academic monologue):** hardest. Often note/summary completion. No conversation
  to help you — rely on prediction and signpost words (`firstly`, `however`, `in conclusion`).

## 5. Distractor signals and self-corrections

When a speaker says `actually`, `well, no`, `sorry`, `I mean`, `on second thoughts`,
`but`, `however`, `although`, `in fact`, `instead` — the information that follows often
**replaces** what came before. The corrected version is usually the answer.

Example: "The meeting was on Monday — sorry, Tuesday." → answer: Tuesday.

## 6. Error taxonomy (use when reviewing)

| Cause | Signature | Fix |
|---|---|---|
| Lost place | One miss caused several following misses | Answers follow order; guess and move on instantly |
| Missed paraphrase | Recognised the word but missed the meaning | Build paraphrase lists from transcripts |
| Plural/spelling error | Heard the word but wrote singular/misspelt | Listen for final `s`; practise spelling of names |
| Number error | Confused `13/30`, `14/40`, dates | Number drills; write digits |
| Word-limit breach | Wrote 3 words when limit was 2 | Circle the limit before listening |
| Distractor trap | Chose the first-mentioned option | Listen for self-corrections |
| Prediction failure | Did not know what word type to expect | Predict every gap before listening |
| Concentration lapse | Missed an entire section | Daily focused listening practice; sleep well |
| Transfer/copy error | Right answer, wrong on answer sheet | Use transfer time carefully (paper); check spelling |

## 7. Practice method

1. Do a section under exam conditions (one play only).
2. Check answers **with the transcript** — find the exact evidence line for each.
3. Mark the paraphrase used (question wording → transcript wording).
4. Classify each error using the taxonomy above.
5. Replay only the difficult sentences, then shadow/dictate them.
6. Build a personal list of problem numbers, names and spellings.
7. Repeat with a new section; do not simply accumulate full tests without analysis.

Use authentic IELTS Cambridge test books for real past papers.

## 8. Daily drills for Band 8–9

- **Numbers:** 13/30, 14/40, 15/50, dates, prices, phone numbers.
- **Spelling:** names of people, places and streets spelled out letter by letter.
- **Plurals:** listen for and write the final `s`.
- **Dictation:** 5 sentences from a transcript each day, checking every word.
- **Accents:** expose yourself to British, Australian, New Zealand and North American speech.
